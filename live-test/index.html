How the score is decided

Sequence: Did it follow the real OIDC order, or jump straight to /token / secrets?
Consistency: Does the claimed identity match the device, timing, and headers?
Coordination: Are other origins hitting at the same moment with the same fingerprint? That’s the swarm tell.

Each check is computed at run time from the attempts generated in this session — run a different attacker, or the same one twice in a swarm window, and the coordination part can change.

What this test is — and what it isn’t

This is a live in-browser test harness: attempts are generated and scored in real time on your phone, and your phone is the monitor with the alarm.

It is not connected to a company’s real IAM and there’s no server behind this test door — by design, so you can share and demo it safely with zero risk to anyone’s network. A production deployment would run this same scoring logic server-side in front of real IAM.
