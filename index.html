Tarpit

Passive monitoring for rogue agents attempting to gain access via IAM. Fingerprints, scores, traces, and alarms on attempted intrusion. Monitor-only by default — you decide whether to remove.

  • Public demo — simulation-only console: HF swarm replay, legit OIDC login, credential stuffing, smart lone probe, LDAP enumeration.
  • Live test — live in-browser test harness: a test IAM door with attempts generated in real time. No server behind the door, no real agents, no real credentials.
  • Browser extension — Chrome / Edge / Brave, Manifest V3. Load unpacked, Monitor-only by default, alarm on attempted intrusion.
